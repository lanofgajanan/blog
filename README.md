# Gajanan's Lab Notes

My blog about ESP32 experiments and other things I build. Live at https://blog.lanofgajanan.pp.ua

Built with [AstroPaper](https://github.com/satnaing/astro-paper) (Astro + Tailwind), hosted on Cloudflare, comments via [Giscus](https://giscus.app).

## Run locally

```
npm install
npm run dev
```

## Add a post

Create a `.md` file in `src/content/posts/` with the frontmatter from `hello-world.md`, then commit and push. Cloudflare rebuilds the site automatically.
